Game Description#

hololive GoroGoro Mountain is a 3D action game that focuses on a single mechanical concept. The main goal is to carry certain things, called the participants' treasures, up the mountain to reach the top. Gamers interact with the environment by rolling and pushing these objects forward. The objectives of this project are built around physics-based movement that requires control to navigate along a given route.

You can play through the title alone or with others in online co-op mode, and all actions have controller support. The gameplay in hololive GoroGoro Mountain expands on the core idea with a teaming mechanic. When two treasures of the same type touch, they merge into a larger form. This transformation is a key element of the process, directly affecting the object under the player’s control. Successful connection of objects allows you to create larger and larger ones through repetition of actions. The main goal is to form the largest item possible by using this fusion system repeatedly throughout the level.

This action game offers both single and multiplayer options, including online co-op play. In online sessions, several people join forces, each man controlling his own rolling object on his way to the top. The activity is built around maneuvering these things and using physics to navigate the climb. It is necessary to constantly push the chosen idol’s thing up the hill, because the whole process is built on promoting values, merging them to increase and striving for the final goal.
