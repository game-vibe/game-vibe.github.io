Game Description#

Command: Modern Operations returns with an updated interface, new features and content that immerses users in the military operations that took place after World War II. The player has submarines, infantry, aircraft, warships and strategic weapons at his disposal. Power and technique are provided at the start of the match and must be managed wisely.

The process takes place with a view of a global map with elaborate and detailed terrain layers. Using satellite imagery and scanned terrain, players get an unprecedentedly clear battlefield for units. The Command user interface allows you to play in both full screen and windowed mode. Secondary information panels can be installed anywhere on the screen and “bind” hot keys for easy control.

The user will go to Korea, Vietnam, India, Cuba and other countries, where he will participate in military conflicts and try to complete given missions. 600 standard scenarios have an original map and tasks. The “quick match” generator will allow you to start playing immediately. Any user can use the scenario editor to create the terrain and tasks as they wish. The in-game Lua engine allows you to create your own combat units and customize artificial intelligence.
